# Partners Management System

WPF desktop application for managing company partner data.

## Technologies

- .NET Framework 4.7.2
- WPF (Windows Presentation Foundation)
- C#
- MS SQL Server
- ADO.NET

## Features

- View list of all partners
- Add new partners
- Edit partner information
- Delete partners
- Search and filter partners
- Sort by any column

### Requirements

- Windows 7 SP1 or higher
- .NET Framework 4.7.2
- Visual Studio 2019/2022 (for development)
- SQL Server 2012 or higher
